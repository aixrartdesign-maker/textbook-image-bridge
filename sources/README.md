# sources

| 폴더 | 내용 |
|---|---|
| `ko/` | 국문판 조판 소스 v9.6과 책에 쓰인 이미지 전체 — `book/img_new` 새로 만든 사진·일러스트·도판, `book/img` 원고 원본 도판. 빌드 방법은 `ko/README.txt` |
| `en/` `de/` `ru/` | 영문 v2.1·독일어 v1.1·러시아어 v1.1 조판 소스와 언어별로 글자를 다시 넣은 도판 (`img_en`, `img_de`, `img_ru`), 번역 메모리와 도판 작업 도구 |

영문·독일어·러시아어판은 사진과 일러스트를 국문판과 같은 파일로 씁니다. 각 폴더의 README.txt에서 "Korean source package"라고 한 곳은 이 저장소의 `ko/`입니다 (예: `en/book_en/img` → `ko/book/img`, `en/book_en/img_new` → `ko/book/img_new`).

The English, German and Russian editions share their photos and illustrations with the Korean edition: where a README.txt mentions the "Korean source package", use `ko/` in this repository (for example `en/book_en/img` → `ko/book/img`, `en/book_en/img_new` → `ko/book/img_new`).
